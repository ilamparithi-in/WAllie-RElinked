Security & Privacy Disclaimers
  • Client IP & Network Exposure: Generating previews locally causes your desktop client to send direct HTTP/HTTPS requests to the shared URL's host server. This exposes your device's public IP address, TLS fingerprint, and headers to that website before you even send the message. Native WhatsApp normally proxies these requests through your primary phone or WhatsApp infrastructure.
  • Client-Side JavaScript Hooking: Injects an interceptor into WhatsApp Web's main-world JavaScript runtime (WAWebLinkPreviewChatAction.getLinkPreview) to substitute desktop OpenGraph models directly into the message composer.
Desktop Parity Note: Official WhatsApp Web runs inside a browser sandbox and cannot make cross-origin requests. WhatsApp Desktop for Windows works around this by using a native C++ Edge WebView2 bridge (cr:17219.getWindowsBridge().linksPreview) to scrape previews locally. This extension provides the equivalent bridge architecture on Linux.
